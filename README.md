# coc-player-props

存放 CoC 跑團用、**設計給玩家直接操作**的互動網頁道具（社群媒體模擬介面、線索網頁等）。

**不含KP限定內容**（劇本、真相、線索答案等留在私有 repo `coc-modules` 裡，這個 repo 只放玩家看得到的東西）。

透過 GitHub Pages 部署，靜態網頁，無後端。

## 目錄結構

```
/index.html                     — 網頁一覽入口
/銓山鎮失蹤調查/
  IG互動介面.html                — 角色社群媒體模擬（動態消息、限時動態、DM）
```

之後新增劇本的玩家道具，依同樣模式在根目錄開新資料夾即可。
